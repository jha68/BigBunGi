# 빅분기 · 실기 연습실

빅데이터분석기사 실기 스타일의 **직접 만든 50문제**를 풀고, 브라우저에서 실제 Python을 실행하는 학습 웹앱입니다.

배포 주소: **https://bigbungi.junununseo.com**

## 제공 기능

- **1유형 30문제:** 조건 추출, 결측치, IQR·Z-score, 취소 거래, 날짜·전환율, merge, 정규화, 피벗, CAGR, 중복 제거, 부서별 대체, 문자열 정제, 가중평균, 재구매율, 구간화, 이동평균, 누적 도달, 왜도·로그 변환.
- **2유형 10문제:** 이진분류(ROC AUC), 회귀(RMSE), 다중분류(Macro F1). 결측치·범주형·잡음이 있는 학습/평가 데이터와 CSV 제출 채점. 통신·주거·게임·의료·중고차·와인·마케팅·배달·설비·신용 위험 데이터.
- **3유형 10문제:** 대응·단일표본 t-검정, ANOVA, 상관분석, OLS, 카이제곱, 비벌점 로지스틱 회귀, 오즈비·민감도·특이도, Welch·Levene, 카이제곱 적합도, 두 비율 z검정·Wilson 구간, Spearman, 중첩 모형 F검정.
- 코드 편집기, `Ctrl/Cmd+Enter` 실행, stdout·경고·Python traceback, 데이터프레임·그래프 표시, 실행 중지와 60초 제한.
- 선택 영역의 파란색 강조·테두리, 줄 번호·Python 문법 강조·자동 줄바꿈이 있는 읽기 전용 기준 풀이.
- 데이터 미리보기·변수 설명·CSV 다운로드, 단계별 힌트, 기준 풀이, 풀이 노트, 진행률, 모바일 화면.
- 코드·답안·노트·진행률을 브라우저에 자동 저장합니다. 개인용 비밀번호 로그인·기기 간 동기화도 지원하며, 아래 Cloudflare 최초 설정을 완료해야 활성화됩니다.
- **Gemini 튜터:** 현재 문제·작성 중인 코드·실행 결과를 첨부하는 문제별 AI 대화. 개인 API 키, 모델 선택, 코드 문법 강조, 오류 안내·재시도·응답 중지.

## 개인용 비밀번호 로그인 / 기기 간 동기화

**Cloudflare 최초 연결을 완료하기 전에는 기존 브라우저 저장 모드로 동작합니다.** 비밀번호 창만 띄워 놓고 서버에 저장되는 것처럼 표시하지 않습니다. GitHub Pages는 화면·문제·데이터를 계속 제공하고, Cloudflare Worker와 D1이 개인용 로그인과 기록 저장을 담당합니다.

[저장소 Actions secrets](https://github.com/jha68/BigBunGi/settings/secrets/actions)에 다음 세 값을 등록합니다. 비밀번호와 토큰을 채팅·소스 코드·일반 repository variables에 입력하지 마세요.

| Secret 이름 | 등록할 값 |
| --- | --- |
| `CLOUDFLARE_ACCOUNT_ID` | `junununseo.com`을 관리하는 Cloudflare 계정의 Account ID |
| `CLOUDFLARE_API_TOKEN` | 해당 계정의 Workers Scripts 편집·D1 편집·Account Settings 조회, 해당 도메인의 Zone 조회·Workers Routes 편집·DNS 편집 권한이 있는 토큰 |
| `SYNC_PASSWORD` | 앱에 로그인할 개인용 비밀번호. 12–128자. |

토큰은 [Cloudflare API Tokens](https://dash.cloudflare.com/profile/api-tokens)에서 만들고, 리소스는 해당 계정과 `junununseo.com`으로 제한합니다. Account ID는 Cloudflare 도메인 Overview에서 확인합니다. 토큰은 서버와 데이터베이스를 생성하기 위한 관리 권한이며, 웹앱 방문자에게 전달되지 않습니다.

이 기능은 **Workers/D1 Free 플랜 전용**으로 운영합니다. Cloudflare 대시보드에서 Workers 플랜이 Free인지 확인한 다음, [저장소 Actions variables](https://github.com/jha68/BigBunGi/settings/variables/actions)에 `SYNC_FREE_PLAN_CONFIRMED` = `true`를 등록합니다. 계정이 이미 Workers Paid이면 등록하지 마세요. 무료 확인 표시가 없으면 secret을 모두 등록해도 서버 리소스를 만들지 않습니다. 이 표시는 사용자가 대시보드에서 확인했다는 뜻이며, 청구 정보를 API로 자동 판정하는 기능은 아닙니다. 스크립트는 플랜 업그레이드·유료 구독·결제 등록을 수행하지 않습니다. Free 플랜의 한도를 넘으면 Cloudflare의 무료 한도 제한에 따라 동기화가 실패할 수 있으며, 브라우저 기록은 남습니다. 기존 Gemini API 요청의 모델별 요금은 별도입니다.

등록 후 [Actions](https://github.com/jha68/BigBunGi/actions/workflows/pages.yml) → **Run workflow**를 실행합니다. 기존 배포 절차가 다음을 자동으로 수행합니다.

1. 서버·화면 테스트 실행.
2. `bigbungi-sync` D1 데이터베이스를 생성하거나 기존 데이터베이스 재사용. 기존 기록은 삭제하지 않음.
3. `bigbungi-sync` Worker와 `bigbungi-api.junununseo.com` 사용자 지정 도메인 연결. Cloudflare가 API 도메인의 DNS를 관리하며, 기존 앱 도메인의 레코드는 유지.
4. 비밀번호를 계정별 salt와 PBKDF2-SHA256으로 해시하여 Worker secret으로 배포. 원문 비밀번호·관리 토큰은 화면 파일에 포함하지 않음.
5. 실제 HTTPS 로그인과 인증된 기록 조회를 확인한 후, 로그인 화면이 활성화된 GitHub Pages 빌드 배포. 관리 권한·도메인 연결 검증에 실패하면 활성화하지 않음.

이후에는 일반 작업 재배포 시 서버와 화면을 함께 갱신합니다. 비밀번호를 바꾸려면 `SYNC_PASSWORD` secret을 수정하고 다시 배포합니다. 이전 비밀번호로 발급한 세션은 새 비밀번호에서 무효가 됩니다. 세 secret 중 일부만 있는 경우에는 불완전한 설정으로 보고 배포를 중단합니다. 모두 없을 때는 기존 브라우저 저장 모드가 유지됩니다. **활성화 후 secret 세 개를 모두 삭제하면 다음 배포는 브라우저 저장 모드로 전환되므로, 로그인 유지가 필요하다면 삭제하지 마세요.**

사용 흐름은 다음과 같습니다.

- 비밀번호로 로그인하면 서버에 저장한 코드·입력 답안·풀이 노트·문제별 통과 여부와 진행도를 복원합니다. Gemini API 키와 선택 모델도 별도 암호화 저장소에서 자동 복원합니다. AI 대화는 현재 탭에서만 유지합니다.
- 첫 연결 시 기존 브라우저 기록을 서버로 가져올 수 있습니다. 서버와 브라우저 기록이 다르면 선택 전에 양쪽 기록을 파일로 백업할 수 있습니다.
- 수정 후 약 0.8초 뒤 서버 저장을 시도하며, 상단의 **서버 저장됨** 표시로 완료 여부를 확인합니다. 최대 기록 크기는 요청당 1MB입니다.
- 네트워크 오류·세션 만료 시 브라우저 기록을 유지합니다. 다시 저장하거나 로그인 후 이어갈 수 있습니다. 기기를 바꾸기 전에는 저장 완료를 확인하세요.
- 두 기기가 같은 서버 버전에서 수정한 경우, 나중 저장은 충돌로 처리하며 자동으로 덮어쓰지 않습니다. 현재 기록 백업, 서버 기록 선택, 명시적인 서버 덮어쓰기를 지원합니다. 열린 다른 기기에 변경 사항을 실시간 반영하지는 않습니다.
- 서버 세션은 HttpOnly·Secure·SameSite=Strict 쿠키로 관리하며 7일 후 만료됩니다. 로그아웃하면 서버 세션과 Gemini 메모리 상태를 지웁니다. 브라우저 백업은 보존되며, 공용 기기에서는 사용 후 브라우저 사이트 데이터도 지워 주세요.
- GitHub Pages의 문제·데이터 파일은 공개 상태를 유지합니다. 비밀번호는 학습 기록 API 접근을 보호하며, 정적 파일 자체를 비공개로 바꾸지는 않습니다.

서버 테스트: `cd sync && npm ci && npm test`. 실제 Worker 런타임과 로컬 D1에서 인증·충돌·로그아웃·만료·로그인 시도 제한을 검사합니다. 두 브라우저 통합 테스트는 `VITE_SYNC_API_URL=https://bigbungi-api.junununseo.com npm run build --prefix web` 후 `web/dist`를 4195번 포트로 제공하고, `node sync/test-server.mjs`와 `.venv/bin/python tests/browser_sync.py`를 실행합니다. 외부 Cloudflare 계정이나 실제 비밀번호를 사용하지 않습니다.

## Gemini 질문하기

1. 문제를 선택하고 왼쪽 **문제·데이터·노트 옆의 AI 질문** 탭을 엽니다.
2. [Google AI Studio](https://aistudio.google.com/apikey)에서 발급한 **본인의 API 키**를 입력하고 **키 연결**을 누릅니다. 키는 채팅이나 저장소에 올리지 마세요.
3. 키로 사용 가능한 텍스트 모델을 조회한 뒤, 무료 플랜 지원 모델 또는 입력·출력 중 하나라도 $1 미만인 모델을 가격순으로 표시합니다. 처음에는 가장 저렴한 모델을 선택하고, 저장한 모델이 있으면 그 선택을 복원합니다.
   모델 이름과 선택 목록에 **입력·출력 참고 단가(USD / 100만 토큰)**를 함께 표시합니다. 장문 입력 요금이 다른 모델은 가격 범위와 기준 토큰 수를 표시합니다. `web/src/gemini-prices.json`은 2026-11-01에 조회한 LiteLLM의 Google Gemini 요금표 스냅샷이며, 출처 커밋과 Google 공식 요금 링크를 포함합니다. 실시간 청구 조회가 아니며 새 모델·미확인 ID는 `가격 확인 필요`로 표시합니다. 무료 한도·캐시·배치 요금과 latest 별칭 변경은 별도입니다.
4. 질문을 입력하고 전송 버튼이나 `Enter`로 보냅니다. `Shift+Enter`는 줄바꿈이며, 한글 조합 중 Enter는 전송하지 않습니다. 답변은 스트리밍으로 생성되는 대로 표시합니다. **전송 순간의 최신 문제·코드·변수 설명·데이터 미리보기**가 자동 첨부됩니다. 최근 실행 결과·오류는 첨부 내용에서 켜고 끌 수 있습니다.
5. 같은 문제의 최근 6개 성공한 질의·응답을 함께 참고합니다. 다른 문제로 바꿔도 대화는 섞이지 않습니다.
6. AI 질문 상단의 **확대** 버튼을 누르면 문제 패널 전체를 대화와 하단 입력창으로 채웁니다. 제목·탭·연결 설정은 숨기며, **축소** 버튼이나 `Esc`로 기존 화면으로 돌아갑니다. 작성 중인 질문과 대화는 유지됩니다.

**노트 자동 생성:** 현재 문제에서 AI 질문·답변을 나눈 뒤 **노트 → AI 대화로 노트 생성**을 누릅니다. AI 질문에서 연결한 키와 현재 선택 모델을 그대로 사용하며, 이 문제의 성공한 대화만 보내 문답별 `Q. 질문 요지 한 줄 / A. 답변 핵심 한 문장`으로 아주 짧게 요약합니다. 질문은 60자, 답변 설명은 100자 이내를 요청합니다. 답변에 코드가 있으면 필요한 Python 핵심 코드 1~3줄만 코드 블록으로 첨부합니다. 대화에 없는 새 코드·긴 예제·제목·추가 해설·조언·체크리스트는 만들지 않도록 지시합니다. 노트 요약 요청에는 현재 코드·문제 데이터는 보내지 않습니다. 실제 프롬프트는 `web/src/gemini.js`의 `NOTE_PROMPT`에 있습니다. 다른 문제의 대화와 실패·중지한 요청은 포함하지 않습니다. 생성 결과는 미리보기로 보여주며, **내 노트에 추가**를 눌러야 기존 메모 아래에 추가·저장됩니다. 저장 후에는 Markdown 보기로 전환해 코드 블록의 문법 강조·줄바꿈·들여쓰기를 그대로 표시합니다. **노트 편집**에서 원문을 수정하고 **노트 보기**로 확인할 수 있으며, 저장된 기존 노트도 같은 방식으로 표시합니다. 생성 중 메모를 수정하거나 문제를 바꿔도 기존 메모는 보존됩니다. 추가한 노트는 브라우저에 자동 저장되고, 아직 추가하지 않은 미리보기는 현재 탭에서만 유지됩니다. 서버 로그인 모드에서는 복원된 대화로도 노트를 생성할 수 있습니다.

**키·모델 자동 저장:** 서버 로그인을 사용하면 검증에 성공한 개인 Gemini 키와 선택 모델을 자동 저장하며, 새로고침·재로그인·다른 기기에서도 자동 연결합니다. 사용 가능한 모델 목록에서 저장한 모델이 사라지면 가장 저렴한 모델로 연결하고 안내합니다. AI 질문에서 **저장된 키·모델 삭제**를 누르면 서버 설정도 삭제됩니다. 로그아웃은 저장된 설정을 삭제하지 않습니다.

API 키·모델은 로그인 비밀번호에서 파생된 서버 비밀값으로 HKDF 키를 만들고 AES-256-GCM으로 암호화해 D1의 별도 테이블에 저장합니다. 저장할 때마다 새로운 nonce를 사용하며 인증된 HTTPS 요청에서만 복호화해 반환합니다. 서버도 복호화할 수 있는 저장 시 암호화 방식이며 종단 간 암호화는 아닙니다. 평문 키는 localStorage·sessionStorage·학습 기록 백업·URL·배포 파일·프롬프트에 저장하지 않습니다. 서버 로그인 비밀번호를 바꾸면 이전 키를 복원할 수 없어 Gemini 키를 다시 연결해야 합니다. 설정 저장·복원에 실패하면 기존 데이터를 지우지 않고 재시도를 안내하며, 다른 기기와 충돌하면 명시적으로 다시 저장하기 전까지 덮어쓰지 않습니다. 서버 동기화를 사용하지 않는 로컬 개발 모드에서는 기존처럼 탭 메모리에서만 유지합니다.

**AI 대화 자동 저장:** 서버 로그인 모드에서는 질문·답변·코드 블록·오류를 문제별로 암호화해 D1에 저장하고 새로고침·재로그인·다른 기기에서 복원합니다. 대화는 기존 무료 Worker/D1을 사용하며 추가 유료 서비스는 없습니다. 작성 중인 질문 초안과 노트 미리보기는 현재 탭에만 남습니다. 질문 시작·답변 완료 시 바로 저장을 시도하고, 스트리밍 중에는 최대 약 2초마다 저장해 쓰기 요청을 줄입니다. 저장 완료 전 접속이 끊기면 마지막 저장 이후의 답변 일부는 복원되지 않을 수 있으며, 중단된 답변은 재시도할 수 있습니다. 저장 상태·오류·충돌은 AI 입력창 위에 표시합니다. 실패 시 메모리의 대화를 유지하고 재시도·내려받기를 제공하며, 저장 전 페이지 이탈을 경고하고 로그아웃을 막습니다. 다른 기기와 충돌하면 명시적으로 다시 저장해야 하며, 그때 다른 기기의 대화와 아직 저장하지 않은 변경만 합쳐 이미 삭제된 옛 대화를 되살리지 않습니다. **이 문제의 AI 대화 지우기**는 서버에서도 지웁니다. 코드만 초기화·로그아웃·키/모델 삭제는 대화를 지우지 않습니다. 문제당 200문답, 요청 512KiB, 질문 4,000자·답변 60,000자 제한이며, 초과 시 자동 삭제하지 않고 저장 오류를 표시합니다. 대화는 브라우저 저장소·일반 학습 기록 백업에 포함하지 않습니다. 서버 없는 로컬 모드의 대화는 탭에서만 유지됩니다. 이 기능 배포 전에 이미 새로고침으로 사라진 대화는 복구할 수 없습니다. 내 노트에 추가한 요약은 기존 학습 기록으로 저장됩니다.

대화는 AES-256-GCM과 문제 ID에 묶인 인증 데이터로 암호화합니다. 배포가 Worker의 별도 `HISTORY_KEY`를 한 번 자동 생성하며 기존 키를 계속 유지하므로 로그인 비밀번호를 바꿔도 대화는 유지됩니다. 추가 GitHub Secret 등록은 필요 없습니다. Cloudflare Worker의 `HISTORY_KEY`를 삭제하지 마세요. 데이터가 있는데 키가 사라지면 배포는 새 키로 덮어쓰지 않고 중단합니다. 서버도 복호화할 수 있는 저장 시 암호화이며 종단 간 암호화는 아닙니다.

질문은 브라우저에서 Google Gemini의 스트리밍 API로 직접 전송됩니다. 키는 Google 요청의 `x-goog-api-key` 헤더에 사용하며, 프롬프트와 응답의 동일한 키는 마스킹합니다. 스트리밍이 중단되면 받은 내용과 오류를 표시하고, 실패한 답변은 다음 질문이나 노트 요약에 완료된 대화로 포함하지 않습니다. 입력한 키의 할당량과 요금 정책이 적용됩니다. 키에 웹사이트 제한을 설정했다면 운영 도메인을 허용해야 합니다. 키는 웹앱의 AI 질문에서 연결하고, 소스 코드·GitHub Secrets·`VITE_*` 환경변수에 넣지 마세요.

전체 CSV·기준 풀이·정답 키·평가 정답 라벨은 첨부하지 않습니다. Gemini는 Python을 직접 실행하지 않으므로 제안 코드는 에디터에서 직접 실행하여 확인하세요. 답변의 코드 블록은 읽기 전용이며 자동으로 실행하지 않습니다.

## 실행 구조

React + CodeMirror + Vite의 **정적 사이트**입니다. Python 3.12(Pyodide)는 Web Worker 안에서 실행되므로 사용자 코드가 서버나 개발 환경에서 실행되지 않습니다. Python 풀이와 채점은 API 키 없이 작동하며, 선택 기능인 Gemini 튜터에만 개인 키가 필요합니다. 로그인·기록 저장·Gemini 설정 암호화 보관에는 Cloudflare Worker와 D1을 사용합니다.

첫 접속에는 jsDelivr에서 Python 런타임과 pandas·NumPy를 다운로드합니다. scipy·scikit-learn·statsmodels·matplotlib는 코드의 import에 따라 추가 로드됩니다. 첫 실행에는 인터넷이 필요하며 이후 브라우저 캐시를 활용합니다. multiprocessing·임의의 네이티브 패키지·서버 파일 접근은 지원하지 않습니다. 각 실행은 새로운 풀이 네임스페이스와 새로운 `data/` 작업 폴더를 사용합니다.

데이터와 문제는 고정 시드로 직접 생성한 합성 자료이며 실제 응시자의 정보나 원본 기출 데이터는 포함하지 않습니다. 공개된 최근 기출 복원 자료의 유형·문제 형식만 참고했습니다. 공식 기출문제나 공식 채점 시스템이 아닙니다.

정적 학습 사이트의 특성상 정답·평가 라벨도 배포 파일에 포함됩니다. 이는 자기 학습용 채점이며 부정행위 방지가 필요한 시험·인증 용도로 사용하면 안 됩니다. 2유형의 점수·통과 기준은 연습용이고, 모델의 정확한 지표도 함께 표시합니다.

## 로컬 개발

Python 3.12와 Node.js 22 이상을 사용합니다.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m bigbungi.prepare
.venv/bin/python -m bigbungi.model_access --offline
cd web
npm ci
npm run dev -- --port 5173
```

`bigbungi.prepare`는 CSV, 정답, 해설, 미리보기를 `web/public/content/`에 생성합니다. 소스가 달라질 때만 재생성하며 `--force`로 강제로 갱신할 수 있습니다. 기준 정답은 반올림된 실제 배포 CSV를 읽어 다시 계산합니다. 생성 파일은 Git에 넣지 않고 배포 시 재현합니다.

```sh
# 저장소 루트: 실제 CSV로 50개 기준 풀이와 모델 성능 검증
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 .venv/bin/python -m unittest discover -s tests -p 'test_*.py' -v

# 위 검증이 만드는 scikit-learn 지표 fixture와 JavaScript 채점 결과 비교
cd web
npm test
npm run build
npm run preview -- --port 4173 --strictPort
```

브라우저 통합 테스트는 개발 서버를 실행한 뒤 저장소 루트에서 실행합니다.

```sh
CHROMIUM_PATH=/usr/bin/chromium .venv/bin/python tests/browser_smoke.py
# Ctrl/Cmd+Enter, 드래그 선택 강조, 읽기 전용 해설의 문법 강조 검증
CHROMIUM_PATH=/usr/bin/chromium .venv/bin/python tests/browser_editor.py
# Gemini 컨텍스트·대화 분리·키 보관·오류·모바일 UI 검증 (Google 응답은 모의 데이터)
APP_URL=http://127.0.0.1:5173/ CHROMIUM_PATH=/usr/bin/chromium .venv/bin/python tests/browser_gemini.py
```

실제 WebAssembly Python에서 50개 기준 풀이를 실행하고 채점하며 오류·DataFrame·그래프·중지·자동 저장·모바일 탐색을 검증합니다. 클라우드 프록시의 CA를 Chromium이 신뢰하지 않는 경우 테스트는 Python의 검증된 TLS 전송으로 CDN만 연결합니다. TLS 및 Pyodide 패키지 해시 검증은 유지합니다.

Gemini 테스트는 Google의 HTTP 응답을 모의 처리하고 실제 Python 오류를 컨텍스트에 넣어 검증합니다. 유효한 개인 키가 없는 개발 환경에서는 실제 Gemini 답변 생성까지 검증했다고 간주하지 않습니다.

## 문제 풀이

1. 문제를 선택하고 `data/파일명.csv`로 데이터를 읽습니다.
2. 1·3유형은 문제에 안내된 키로 `answers` 딕셔너리를 작성합니다. 실행 후 답안 입력란에 자동 반영되며 직접 수정할 수도 있습니다.
3. 2유형은 `id`와 지정된 예측 열로 `submission.csv`를 저장합니다. `index=False`를 사용합니다.
4. **코드 실행 → 채점하기** 순서로 확인합니다. 코드가 바뀌면 다시 실행해야 합니다.
5. 막히면 단계별 힌트나 해설을 열어 보고 다시 작성합니다.

채점 이력(통과 여부와 무관하게 1회 이상 채점)이 있는 문제를 다시 열거나 현재 문제를 다시 클릭하면 **다시 풀기** 알림이 나타납니다. **코드만 초기화**는 해당 문제의 초안을 기본 코드로 바꾸고, 노트·AI 대화·입력 답안·통과/채점 기록·다른 문제의 코드는 유지합니다. **이어서 풀기**나 `Esc`는 코드를 그대로 둡니다. 서버 로그인 모드에서는 AI 대화도 새로고침 후 복원되며, 재풀이 초기화는 대화를 지우지 않습니다.

## GitHub Pages / 도메인

`main`에 push하면 `.github/workflows/pages.yml`이 다음을 수행합니다.

1. 고정 버전 Python·Node 환경에서 원본 데이터와 정답 생성.
2. Python 문제·모델 검증 및 JavaScript 채점 검증.
3. Vite 빌드 후 GitHub Pages 아티팩트 배포.
4. Pages의 도메인 설정을 확인하고, 공개 HTTPS 주소의 HTML·스크립트·Python worker·50문제 카탈로그를 실제 요청으로 검증.

Cloudflare DNS 레코드는 다음과 같습니다. DNS 레코드를 직접 설정한 경우 Cloudflare API 토큰은 필요하지 않습니다.

| 종류 | 이름 | 대상 | 프록시 |
|---|---|---|---|
| CNAME | `bigbungi` | `jha68.github.io` | DNS 전용 |

저장소 관리자는 Settings → Pages에서 Source를 GitHub Actions로 선택하고 Custom domain에 `bigbungi.junununseo.com`을 저장합니다. 이 관리 설정은 GitHub 기본 배포 토큰으로 수정할 수 없습니다. 인증서 발급 후 Enforce HTTPS를 활성화합니다. DNS 전파와 인증서 발급은 별도로 시간이 걸릴 수 있습니다. 상대 경로로 빌드하므로 기본 주소 `https://jha68.github.io/BigBunGi/`와 사용자 지정 도메인에서 모두 실행할 수 있습니다.
